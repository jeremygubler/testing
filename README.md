# testing

Sandbox repository for prototypes.

## Projects

- **[`autobattler/`](autobattler/)** — Aetherclash, a commercially-oriented
  auto-battler (Teamfight-Tactics-style, original IP) built platform-agnostically
  in Godot 4, prepared for a later licensed Switch/eShop port. See
  [`autobattler/README.md`](autobattler/README.md).
- **[`monsterrpg/`](monsterrpg/)** — Grundgerüst für ein 3D-Monster-Sammel-RPG
  in Godot 4 (eigene IP, Platzhalter-Primitive): Overworld mit freier oder
  rasterbasierter Bewegung, rundenbasiertes Kampfsystem, Typenmatrix,
  Zufallsbegegnungen, Team/Inventar und Speichern. Siehe
  [`monsterrpg/README.md`](monsterrpg/README.md).
- `subway-surfers.html` — standalone Three.js endless-runner prototype.
